# Welcome to TPD!


**Titan Pulse Dynamics** develops **ARISE**, an open, modular CubeSat platforms and **HIVE**, our work on distributed AI and orbital computing.

**We build space technology for a more capable and accessible future.**

**ARISE-1** is the first generation of our ARISE platform. It is an open-source collaboration project built upon open-source heritage missions and technologies, including the OreSat platform by Portland State Aerospace Society (PSAS), Oregon, USA, and OpenLST by Planet Labs. Building on these openly available designs and other heritage technologies, ARISE-1 brings together proven approaches from different projects and develops them into an industrial-grade, high-reliability CubeSat platform.
